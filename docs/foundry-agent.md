# Microsoft Foundry Agent

## Agent

`ai-it-support-agent`

## Purpose

The agent provides AI-assisted analysis for internal IT support requests.

## Responsibilities

The agent:

1. Identifies the issue category.
2. Recommends a priority.
3. Summarizes the problem.
4. Provides troubleshooting steps.
5. Recommends the next action.
6. Asks follow-up questions when necessary.

## Issue Categories

- Hardware
- Software
- Network
- Account & Access
- Security
- Other

## Priority Levels

- Low
- Medium
- High
- Critical

## Human Oversight

The AI recommendation is presented to the user and can be changed before the ticket is submitted.

The AI therefore assists the workflow without replacing human control.
