# Power Apps

## Screen 1 — IT Support

The main screen allows employees to enter:

- Name
- Email
- Priority
- Problem description

The screen also provides AI-powered analysis.

## Screen 2 — IT Ticket Overview

IT staff can:

- Search tickets
- Filter by status
- Filter by priority
- Review tickets
- View ticket assignments

## Screen 3 — Ticket Details

IT staff can:

- Review ticket information
- Update ticket status
- Assign an IT employee
- Save changes

## AI Integration

The `Analyze with AI` button sends the problem and employee email to Power Automate.

The returned AI analysis is displayed in the application.

The recommended priority is extracted from the AI response and automatically selected in the priority field.

The user can manually change the priority before submitting the ticket.
